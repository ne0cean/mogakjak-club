# AI컨닝데이 2026 — 분석

2026-09-02 캡처 기준. 재구축에 필요한 것 위주로 정리.

## 1. 무엇이 특별한가 (모각작이 컨닝할 것)

### 1-1. AI 인터뷰 신청서 (핵심 메커니즘)

신청서를 빈 폼으로 주지 않는다. 흐름:

1. 사이트가 정교한 인터뷰 프롬프트를 제공 (`prompt-interview.md` 전문)
2. 지원자가 그 프롬프트를 자기 AI(ChatGPT, Claude Code 등)에 붙여넣음
3. AI가 지원자의 작업 기록을 근거 수집 → 초안 → 인터뷰 → 검토 → JSON 출력
4. 지원자가 JSON을 신청서의 한 칸에 붙여넣으면 폼 전체가 자동완성
5. 각 칸은 저장 전 직접 수정 가능

프롬프트 자체가 제품이다. 특징: 근거 수집 전 열람 범위 동의를 받게 함, 금지 표현
목록(비유·대구·은어·이중피동)으로 AI 냄새를 차단, 서브에이전트 검토 단계 내장,
불확실한 필드는 키째로 빼게 함. JSON 키는 caseTitle / caseProblem / caseProcess /
caseResult / caseBuild 5개.

모각작 이식 아이디어: 모임 신청서나 프로젝트 소개서를 같은 방식으로. "빈칸 공포"를
없애면서 결과물 품질 하한을 프롬프트가 보장한다.

### 1-2. 신청 상태 트래커

/me 페이지: 신청 완료 → 검토(9/4 마감) → 선발 결과(9/7 발표) 3단계 타임라인 점 그래프.
할 일 체크리스트(참가 신청/워크플로우 고치기/프로필 다듬기)가 완료 상태 뱃지와 함께.
공개 프로필 카드에는 가져온 워크플로우 제목 + 쓰는 도구 칩 목록이 표시된다.
조 편성·네트워킹 매칭용 관심사 선택(각 3개 제한)이 신청서에 내장.

### 1-3. 손그림 질감 시스템

일러스트가 미세하게 흔들리는 "boil" 효과: SVG `feTurbulence` + `feDisplacementMap`
필터 6종(`#boil-1..3`, `#boil-v1..3`)을 body 상단에 정의해 두고 일러스트에 순환 적용.
종이 질감 배경 + 티켓 톱니 모양 섹션 경계와 함께 아날로그 무드를 만든다.

## 2. 디자인 토큰 (css/에서 추출한 실값)

```css
--orange: #fd5b27;        /* 메인 오렌지 */
--orange-deep: #e2491a;
--orange-soft: #ffd5c6;
--orange-on-dark: #ff6f3d; /* 다크 배경 위 오렌지 보정 */
--ink: #332d2b;           /* 다크 브라운 (배경) */
--ink-sunken: #262220;    /* 더 깊은 배경 */

--display-1: clamp(2.9rem, 5.6vw, 8.6rem); /* 유동 타이포 스케일 */
```

- 본문: Noto Sans KR. 다크(#332d2b) 위 종이색 텍스트, 포인트는 오렌지 단색만.
- 상태색 페어 패턴: `--danger`+`--danger-bg`(같은 색 24% 알파) 식으로 배경 파생.
- CSS에 배지 인쇄 시스템(95mm 명찰, bleed/fold 변수)과 어드민 대시보드 토큰
  (`--admin-*`)까지 들어 있음 — 오프라인 행사 운영 도구 일체를 같은 코드베이스로 해결.
