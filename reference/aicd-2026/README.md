# AI컨닝데이 2026 — 리버스 엔지니어링 레퍼런스

행사 신청 사이트 aicd.teamcandid.kr의 구조·디자인·UX 캡처. 사이트가 2026-09-04까지만
열려 있어서 2026-09-02에 확보했다. 목적은 모각작 페이지에 같은 계열의 신청/프로필/
매칭 UX를 이식할 때 참고하는 것.

주의: 원 저작권은 주최사 Candid에 있다. 이 폴더는 학습·참고용 내부 레퍼런스이며,
마크업·일러스트·카피를 그대로 재사용하지 않는다. 개인정보는 캡처 시점에 마스킹했다
(이름은 홍길동, 이메일은 user@example.com으로 치환).

## 폴더 구성

| 경로 | 내용 |
| --- | --- |
| `ANALYSIS.md` | 핵심 분석 — 디자인 시스템, UX 메커니즘, 모각작 이식 가이드 |
| `prompt-interview.md` | 이 사이트의 백미인 "AI 인터뷰 프롬프트" 전문 (신청서 자동완성 메커니즘) |
| `raw/landing-anon.html` | 랜딩 페이지 전체 HTML (비로그인, 756KB, 일러스트 인라인 포함) |
| `raw/info-anon.html` | 안내 페이지 전체 HTML (비로그인) |
| `css/*.css` | 빌드된 CSS 3본 전체 (디자인 토큰, 배지 인쇄 시스템, 어드민 스타일까지 포함) |
| `dom/*.skeleton.txt` | 로그인 페이지들의 DOM 구조 덤프 (태그+클래스 트리, PII 마스킹) |
| `text/me-pipeline.txt` | 신청서 페이지 전체 텍스트 (폼 구조·문항·플레이스홀더) |
| `shots/*.png` | Playwright 풀페이지 캡처 (landing 17592px, info) |
| `fonts/subset-1.woff2` | 사이트 폰트 서브셋 (사이트 소멸 대비) |

## 캡처 방법 기록

- 공개 페이지(/, /info)와 CSS, 폰트: curl 직접 수집
- 로그인 페이지(/me, /me/pipeline): Chrome 확장으로 DOM 구조 덤프. 원문 HTML 반출은
  확장의 데이터 필터에 걸려서(실제로 계정 이메일이 박혀 있었음) 구조+텍스트로 대체
- 스크린샷: Playwright fullPage (headless라 스크롤 트리거 애니메이션 일부는 미발화
  상태로 찍힘 — 어두운 구간이 그것. 실제 렌더는 raw HTML 참고)
